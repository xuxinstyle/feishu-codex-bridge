## 修正清单

| 原说明 | 当前事实及调整 |
| --- | --- |
| 使用 `tool/feishu-codex-bridge/` 路径 | 独立仓库从根目录运行 `.\setup.ps1` 和 `.\start.ps1` |
| 初始化后填凭据即可启动 | secrets 不自动同步到已有运行配置，填写或修改后需重新 setup 并重启 |
| 引用不存在的新名称模板 | 补齐 Codex 专用模板；保留 Cursor 旧文件的兼容回退 |
| CLI 登录/存在即可使用 | 默认桌面通道需要已登录并打开的客户端及可用本地接口 |
| 自动启动隐含避免所有重复实例 | `IgnoreNew` 仅作用于同一计划任务，不识别手工实例 |
| 达到 10 MB 就轮换日志 | 后台脚本仅在每次启动时检查 10 MiB，运行中不持续轮换 |
| 图片作为 CLI `-i` 输入 | 桌面通道提交本地路径及查看要求，App Server 提交 `localImage` |
| 命令表缺少细节 | 补充查询、重置、指定 task、别名、空格及路径限制；未知命令可能作为普通任务 |
| `/new` 与面板新建近似描述 | `/new` 保留当前名字并重置映射，面板新建生成新名字 |
| `/resume` 与“继续”完全相同 | 无已停止目标时，“继续”提交普通任务，`/resume` 返回提示 |
| 每条任务始终一张卡片 | 通常复用，但编辑限制或最终更新失败时可能发替代卡片 |
| 原按钮“引导” | 正式任务卡按钮为“补充给当前任务” |
| 模型页属于直接回调导航 | 模型刷新、历史、附加等也先回执再后台执行 |
| 默认项目固定是仓库根目录 | setup 写仓库根目录；直接运行未配置时回退用户主目录 |
| 缺少配置加载规则 | 补充进程环境优先、DOTENV_CONFIG_PATH、setup 重写及高级字段不复制 |
| sandbox/审批按每轮 CLI 覆盖 | 当前通过 thread 操作传参；已有桌面 thread 不保证由 env 重新配置 |
| 同名 session 始终同一 thread | 普通 session 复用要求 backend 和模型一致，模型变化可能新建 |
| 最终回复附带客户端会话名 | 当前最终任务卡没有固定附带该名称 |
| 客户端连接总能自动选择 | 多连接需指定，已显式配置的过期路径可能要更新 |
| 模型配置是 session 独立或实时回显 | 普通覆盖按聊天+项目共享，附加覆盖独立；任务入队快照，默认配置启动时刷新 |
| 候选目录代表可用模型 | 目录失败可能回退到代码候选，实际执行仍受 provider/catalog/鉴权限制 |
| 项目发现仅一般历史、全部目录过滤 | 扫描已归档及未归档索引，仅发现结果预先过滤目录，手工项仍需后续检查 |
| 打开项目面板即扫描 | 项目子页导航/翻页/切换不触发扫描；启动、/panel、/project、手动刷新及定时器触发 |
| 历史“全部项目”无范围限制 | 仍受来源、可见性和分页过滤；页面还可能被缓存容量提前清理 |
| 桌面模型重连普遍重试 | 仅普通新 thread 的特定明确拒绝可重试一次 |
| stderr/error 全部回传飞书 | 错误摘要与 debug stderr 日志分开，不能承诺完整回传 |
| 配对码隐含先授权才能执行 | 当前白名单为空不阻断全部普通任务，文档明确该实际限制 |
| 真实验证叙述容易理解为已通过 | 集中列出入口、前提、固定测试模型和输出，并区分脚本用途与本次结果 |
